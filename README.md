
# FormFill

**Stop typing the same information into every form.**

FormFill is a single HTML file. Save your details once, then copy any field, or everything at once, whenever a form asks for them. It runs in your browser and works offline.

**[Live demo](https://nahlcodes.github.io/formfill/)**

## Features
- Sections for personal, address, education and family/emergency details
- Custom fields (LinkedIn, GitHub, student ID, anything)
- One-click Copy per field, plus Copy All in three formats: `Label: Value`, `Label + Value`, `Value only`
- Drag-and-drop reordering within each section (touch, mouse and keyboard)
- Search, dark mode, keyboard shortcuts (Ctrl/Cmd+K)
- Export and import your profile as JSON

## Privacy
- No accounts, backend, analytics or network requests
- Your data is stored in your browser's local storage on your device
- It is **not encrypted**, and clearing browser data deletes it. Use Export to keep a backup
- Don't store passwords or card numbers in it

## Use it
Download `index.html` and double-click it, or open the live demo.
